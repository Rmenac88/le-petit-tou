# Le Petit Tou — décisions prises et informations à confirmer

Document de suivi à partager avec l'association. Mis à jour le 3 novembre 2026.

## Décisions prises

| Sujet | Décision |
|---|---|
| Identifiant de l'appli sur iPhone | Il est conservé à la réinstallation (la personne retrouve ses listes) ; l'appli l'explique clairement. |
| Durées de conservation | 24 mois sans activité (listes, likes, points, suggestions) ; 9 mois pour les jetons de notification. |
| Fournisseur de la carte | Mapbox pour tous les téléphones, déclaré dans la politique de confidentialité et chez Apple/Google. |
| Appareils visés | Tous : iPhone, Android, iPad. |
| Partenaires qui paient pour être mis en avant | Mention « **Sponsorisé** » visible partout ; aucun montant ni promesse dans le texte public. |
| Alcool et public visé | Mention de santé publique sur les adresses d'alcool, à afficher simplement. |
| Photos et textes des fiches | Fournis par l'association Le Petit Tou. |
| Dépôt du code | Il passe en **privé** ; quand l'appli est prête, les anciennes données inutiles seront retirées de l'historique. |
